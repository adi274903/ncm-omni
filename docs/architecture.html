2 · what the producer writes

sample → holdout if group not full shuffle buf 512 shard_%06d.npz · 64 samples ≤ 24 shards ahead EVAL_READY → DONE
Held-out blocks are written first (text 32 · image 24 · audio 16 · video 8) so eval exists before the first shard. Shards are never deleted: both arms must read the same rows. Re-running resumes from the seed + sample count, it does not restart.

3 · one model, two masks — everything else identical

level-parallel · mask_mode=block Each level attends only inside itself. All codes of a level are emitted in one forward pass ⇒ 6 NFE for the whole sample, any modality. Attention FLOPs scale with Σlk², not (Σlk)².
autoregressive · mask_mode=ar Causal over the same 504 positions ⇒ one forward pass per token, capped at T/2 in eval. Same params, same schedule, same vocab — the mask is the only difference, which is what makes the comparison matched.

4 · the loop

Eval decodes greedily and scores exact match against the frozen codec codes, per level: coarse level 0 has 2–3 positions, finest has 64–96. The claim under test — level-parallel reaches the AR arm's quality at NFE=6 — is not yet measured; everything above it is plumbing that has run.
